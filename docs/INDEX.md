# Image Documentation Index

This directory documents system image composition and release artifact definitions.

## Scope
- Image manifests and package selection.
- Bootable disk and virtual-machine image assembly.
- Reproducible filesystem tree generation.
- Image metadata, hashes, partition/boot layout, and validation.

## Ownership
[Wicofe-Build](https://github.com/Waizusora/Wicofe-Build) owns build orchestration and toolchains. [WPM](https://github.com/Waizusora/WPM) owns package management. [Wicofe-Installer](https://github.com/Waizusora/Wicofe-Installer) deploys images. [Wicofe-Update](https://github.com/Waizusora/Wicofe-Update) manages installed-system updates.

## Reproducibility
Record exact source revisions, toolchain versions, package inputs, configuration, and artifact hashes. Do not claim an official release image until its manifest and validation evidence are published.
